MD Previewer for Windows

.md をダブルクリックするだけ。図も数式も Marp スライドも縦書きの文庫レイアウトも、インストールした直後から 完全オフラインで表示できます。

無料でダウンロード GitHub で見る

Windows 10 / 11 専用です。 macOS・Linux には対応していません。

  • 管理者権限なし
  • CDN 不使用
  • MIT ライセンス
  • WebView2 のみ
  1. 1

    インストーラを実行

    管理者権限は要りません。ユーザー単位で入ります。

  2. 2

    .md をダブルクリック

    ドラッグ＆ドロップ、フォルダの右クリックでも開けます。

  3. 3

    保存すれば、すぐ映る

    使い慣れたエディタで保存すると、その場で描き直します。

USE CASES

5 とおりの、ちょうどいい使い道。

機能の数より、どう効くか。よく使われている 5 つの場面を挙げます。

01だれでも

開いて、読むだけ。

同僚から、あるいは AI から受け取った .md を、何の準備もなく読めます。見出しから目次が自動で組まれ、外部エディタで保存すればその場で再読込。フォルダごと渡されたときは、ファイルツリー付きのワークスペースとして開きます。

  • 目次サイドバー
  • ファイル関連付け
  • 保存を検知して再読込
  • 単独 HTML / PDF 書き出し

02プレゼンする人へ

Markdown のまま、発表する。

冒頭に marp: true と 1 行書けば、その文書はもう 16:9 のスライドです。P で「1 枚ずつ / サムネイル一覧 / 縦並び」を切り替え、Z でレーザーポインタ。下にはみ出した本文は見出しを固定したまま自動で縮み、PDF は 1 ページ 1 スライドで出ます。

  • Marp Core を内蔵
  • 3 つの表示モード
  • レーザーポインタ
  • スライドの自動縮小
  • 2 カラム / 図・数式

03研究する人へ

数式を、書く速さで。

KaTeX がインラインもディスプレイも組みます。数式を右クリックすれば MathML と LaTeX をコピーでき、Word にそのまま貼れます。内蔵エディタには YaTeX 風の入力支援 — $+Tab、\begin{}+Tab、a.→\alpha。可換図式は tikz-cd をそのまま書けば、WASM 版 TeX がオフラインで組みます。ファインマン図も平面・立体の幾何作図も、同じように書いた分だけ図になります。

  • KaTeX
  • MathML / LaTeX コピー
  • 数式入力支援
  • tikz-cd 可換図式
  • ファインマン図
  • 幾何作図 2D / 3D

04書く人へ

文庫のかたちで、書く。

付属テーマ bunko.css を選ぶと、本文は 1 行 39 字 × 16 行の縦組みページに流し込まれ、ページの地にノンブルが入ります。段落は本物の本と同じようにページをまたいで割れる。字数と行数を見ながら書けて、ルビも振れます。字数・行送り・書体は歯車から動かせて、その場で組み直します。

  • 39 字 × 16 行の行取り
  • ノンブル
  • ルビ（振り仮名）
  • A4 横に見開き 2 ページの PDF

05こだわる人へ

指の記憶に、道具を合わせる。

内蔵エディタは Vim キーバインドに対応し、w b e は漢字・ひらがな・カタカナの切れ目で止まります。そして Dvorak 配列エミュレータを使っている人のために、コマンドモードのキーだけを、押した物理キーの QWERTY 位置で解釈できます。文章の入力は Dvorak のまま。

  • Vim キーバインド
  • 日本語のワード境界
  • Jupyter 風セルモード
  • Dvorak → QWERTY 転送

多段組みフェンス記法

ウェルギリウス『アエネーイス』の一節を、原文と訳で並べます。

::: columns
### Aeneis I, 462
sunt lacrimae rerum et mentem mortalia tangunt.
+++
### アエネーイス 第 1 歌 462
ものにも涙があり、人の世のはかなさが心を打つ。
:::

`:::` で 1 カラムに戻るので、この段落はまた幅いっぱいに流れます。

ONE KEY EACH

メニューは、ありません。

表示の切り替えも書き出しも、キー 1 つです。

ウィンドウの表示

H
アプリ内のショートカット一覧の表示 / 非表示
M
ダーク / ライト表示の切り替え
S
スタイルの選択（行末の ⚙ でそのスタイル固有の設定。Marpモードでは Marpテーマ。フロントマターを書き換え）
N
セクション自動番号の切り替え
L
行番号の表示切り替え
W
全幅レイアウトの切り替え
Ctrl++ / Ctrl+- / Ctrl+0
ズームイン / アウト / リセット
Esc
開いているモーダルを閉じる（新しいものから順に）

開く・書き出す

E
エディタウィンドウを開く（Vimモード・数式入力補助・文字数カウント）
Ctrl+N
新規の空Markdownファイルを作成
Ctrl+D
インストール先フォルダを Explorer で開く
Alt+← / Alt+→
開いたファイルの履歴を戻る / 進む
Ctrl+クリック
.md リンクを新しいプレビュアのウィンドウで開く（通常のクリックは同じウィンドウで遷移）
X
現在の文書をエクスポート（保存ダイアログで HTML / PDF を選択。PDFはクリック可能なリンクと見出しのしおりを保持）

Marp スライド

Marp 文書のときだけ効きます。下の 4 つはデッキ表示中のみ。

P
Marp表示の切り替え: スクロール → デッキ → 一覧（一覧でサムネイルをクリックするとデッキで開く）
F
全画面表示の切り替え（Marp文書）
A
スライドの自動縮小の切り替え（Marp）
← / → / PgUp / PgDn / Space
前 / 次のスライド（Marpデッキモード）
Home / End
最初 / 最後のスライドへ（Marpデッキモード）
Ctrl+Wheel / ドラッグ
カーソル位置でズーム / スライドをパン（Marpデッキモード）
Z
軌跡付きレーザーポインタの切り替え（Marpデッキモード）

エディタウィンドウ

プレビューで E を押すと開きます。Vim キーバインドは ⚙ 設定 でオンにします。

Ctrl+S
保存してプレビューへ反映（Vim では :w / :wq）
Tab / Shift+Tab
インデント / 逆インデント。数式の中では入力補助が、番号付きリストの中ではマーカー幅への揃えが先に働きます
Ctrl++ / Ctrl+- / Ctrl+0
編集中の文字だけを拡大 / 縮小 / 既定へ（Ctrl+ホイール、:fontsize でも）
Ctrl+V
Excel / Word の表を Markdown の表に変換して貼り付け（Ctrl+Shift+V で一回だけ素のまま、Ctrl+Z 一回で戻ります）
Ctrl+Alt+N / C / X
Marp スライドを挿入 / コピー / カット（Vim では gsi / gsy / gsd）
Ctrl+Alt+T / H
表を挿入 / カーソル列のハイライトを切り替え（Vim では gti / gtc）
]] / [[ / za / zA
次 / 前の見出しへ移動、節を畳む / すべて畳む（Vim ノーマルモード）
gmc / Shift+Enter
--- 区切りの Jupyter 風セルモードを切り替え、セルを実行して次へ（:cellmode でも）
w / b / e
漢字・ひらがな・カタカナの切れ目で止まる単語移動（Vim ノーマルモード。:set dvorak で Dvorak 配列にも対応）

上の 3 つは、アプリの中で H を押すと出る一覧と同じものです。エディタの欄は主なものだけで、セルモードや Vim の全キー、ex コマンドの一覧はエディタの ⚙ 設定 と README でご覧いただけます。
