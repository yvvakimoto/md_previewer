# Markwhen タイムライン

言語指定 **markwhen** のフェンスコードブロックに [markwhen](https://markwhen.com/) のテキストを書くと、
横型のカスケードタイムラインとして描画されます（[@markwhen/parser](https://www.npmjs.com/package/@markwhen/parser) を同梱、
オフラインで動作）。日付は ISO・米国式・欧州式・自然言語いずれもパーサが解決します。

## 基本

- セクション（グループ）は Markdown 風の見出し `#` 〜 `######`
- 期間イベントは `開始 / 終了: ラベル`、単発イベントは `日付: ラベル`
- タグは `#tag`、色はフロントマターで `#tag: 色名` と定義

```markwhen
---
title: プロジェクト計画
#design: blue
#dev: green
#release: red
---

# 企画
2023-01-01 / 2023-02-15: 要件定義 #design
2023-02-01: キックオフ

# 開発
2023-03-01 / 2023-06-30: API 実装 #dev
2023-05-01 / 2023-08-31: UI 実装 #design

## QA
2023-07-15 / 2023-09-15: テスト #dev

# リリース
2023-10-01: 正式リリース #release
```

## 歴史年表（年スケール）の例

期間が長いと時間軸の目盛りは自動で年単位に切り替わります。

```markwhen
# できごと
1989: 平成 改元
1995 / 1996: ある期間
2001-09: 出来事
2011-03-11: 震災
2019-05-01: 令和 改元
2020 / 2022: パンデミック
```

## カレンダー表示（`display: calendar`）

ヘッダに `display: calendar`（または `calendar: true`）を書くと、同じ markwhen データが**月グリッドのカレンダー**として描画されます。
単発イベントはチップ、期間イベントは週をまたぐ帯として、それぞれの日付セルに配置されます
（最初のイベントの月〜最後のイベントの月を連続表示。期間が約 36 ヶ月を超えるとタイムラインへフォールバック）。

**祝日はオンライン実行時のみ**取得してセルに反映します（既定は日本 `country: JP`。`country: US` 等で変更可）。
オフライン時は祝日なしで通常描画され、エラーにはなりません。

```markwhen
---
title: 5月の予定
display: calendar
country: JP
#plan: blue
#dev: green
#event: red
---

# 予定
2024-05-01 / 2024-05-10: 大型連休の準備 #plan
2024-05-07 / 2024-05-24: スプリント開発 #dev
2024-05-15: 定例レビュー #event
2024-05-29: リリース判定 #event
```

ダークモード（`M`）でも配色が追従し、HTML エクスポート（`X`）・Marp スライドにもそのまま含まれます
（オンライン取得済みの祝日はエクスポート成果物にもそのまま焼き込まれます）。
