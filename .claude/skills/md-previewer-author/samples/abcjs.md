# ABC — 楽譜（ABC 記譜）ブロック

言語指定 **abc** のフェンスコードブロックに [ABC 記譜法](https://abcnotation.com/) を書くと、[abcjs](https://github.com/paulrosen/abcjs) によって五線譜 SVG として埋め込まれます。描画のみ（音声再生は非対応）。譜面はインライン SVG なので HTML エクスポートにもそのまま含まれ、`M` キーのダーク/ライト切替にも追従します。

## 1. 単純な旋律

ヘッダ（`X:` 連番・`T:` 曲名・`M:` 拍子・`L:` 既定音価・`K:` 調号）に続けて音符を並べます。

```abc
X:1
T:きらきら星
M:4/4
L:1/4
K:C
C C G G | A A G2 | F F E E | D D C2 |
```

## 2. 調号・拍子・テンポ

```abc
X:1
T:8分の6拍子の例
M:6/8
L:1/8
Q:3/8=80
K:G
G2 A B2 c | d2 B G3 | A2 B c2 d | e2 d B3 |
```

## 3. 和音とスラー・タイ

角括弧 `[...]` が和音、丸括弧 `(...)` がスラー、`-` がタイです。

```abc
X:1
T:和音とスラー
M:4/4
L:1/4
K:C
[CEG] [DFA] (G A) | [CEG]2 z2 | C-C E G | [CEGc]4 |
```

## 4. 歌詞付き（`w:` 行）

`w:` 行で各音符の下に歌詞を割り当てられます。

```abc
X:1
T:歌詞の例
M:4/4
L:1/4
K:C
C D E F | G2 G2 |
w:ド レ ミ ファ ソ-
```

## 5. 複数段（連符・装飾）

```abc
X:1
T:複数段
M:4/4
L:1/8
K:D
|: D2 F2 A2 d2 | (3efe d2 A2 F2 :|
| B2 G2 E2 C2 | D8 |]
```

## 6. 不正な入力時の挙動

abcjs は寛容で、解釈できない行は読み飛ばして描けるところまで描画します（下の例では装飾音だけが残ります）。各ブロックは独立して処理されるので、ある譜面の入力が不完全でもページ内の他のブロックは影響を受けません。レンダリング自体が例外で失敗した場合のみ、その場に `.abc-error` の赤枠ボックスが表示されます。

```abc
X:1
K:C
{g}A %% この後に続く壊れた行は読み飛ばされる
[[[ this is not valid abc
```
