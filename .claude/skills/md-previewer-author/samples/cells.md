# セルモード

エディタウィンドウ（`E` キー）のステータスバーで **`⌗ Cells: ON`** にすると、
`---` 区切りが Jupyter のセルとして扱われます。

このファイルはそのまま Marp デッキなので、セル N がスライド N に対応します。

---

# 2 つのモード

Jupyter と同じ 2 モード制です。

- **編集モード** — 普通に文字を打てます。アクティブセルの左バーは**緑**
- **コマンドモード** — `Esc` で入ります。左バーは**青**、キャレットは消えます

コマンドモードから戻るのは `Enter`（そのまま）か `i`（INSERT へ）。

Vim を ON にしていても同じで、NORMAL モードの `Esc` がコマンドモードへの入口に
なります。INSERT / VISUAL 中の `Esc` は従来どおり Vim のものです。

---

# セルの操作

コマンドモードでの主なキー（全部は `h` で一覧が出ます）。

| キー | 動作 |
| --- | --- |
| `j` / `k` | 次 / 前のセルへ |
| `a` / `b` | 上 / 下にセルを挿入 |
| `d d` | セルを削除 |
| `x` / `c` / `v` | カット / コピー / 下に貼り付け |
| `M` | 下のセルと結合 |
| `1`〜`6` / `0` | 見出しレベルを設定 / 解除 |

どの操作も **`u`（または `Ctrl+Z`）1 回で元に戻ります**。

---

# 実行 = プレビュー同期

「実行」はプレビューをそのセルに合わせることです。

- `Shift+Enter` — 同期して次のセルへ
- `Ctrl+Enter` — 同期してとどまる
- `Alt+Enter` — 同期して下に新しいセルを作る

`Ctrl+Shift+-` でカーソル位置でセルを分割、`Ctrl+Shift+↑ / ↓` でセルを入れ替え。

**`Live: OFF` と組み合わせると**、プレビューは実行したときだけ更新される
完全に手動のワークフローになります。

---

# 区切り記号の扱い

セル区切りとして数えるのは、独立した行の `---` / `***` / `___` です。
ただし次の 2 つは区切りになりません。

コードフェンスの中の `---`：

```yaml
key: value
---
other: value
```

そして**段落の直後の `---`** — これは CommonMark では直前の段落を `<h2>` に
する setext 下線なので、Marp もスライドを切りません。

見出しになる例
---

上の行は「見出しになる例」という `<h2>` です。セル境界ではないので、
このスライドはここで終わりません。

---

# front-matter は保護セル

先頭の `marp: true` ブロックは灰色のバーが付いた**保護セル**として表示されます。

- `j` / `k` / `Home` の移動対象にならない
- 削除・結合・分割・移動はいずれも拒否される

クリックすれば普通に編集できますが、セル操作で壊すことはできません。

---

# Vim の `gg` / `G` はセル内に収まる

編集モードで Vim を使っているとき、セルモード ON のあいだは
`gg` / `G` が**このセルの先頭行 / 末尾行**へ移動します
（前後の空行は飛ばして、実際に中身のある行）。

| キー | セルモード ON | セルモード OFF |
| --- | --- | --- |
| `gg` | このセルの最初の内容行 | 文書の 1 行目 |
| `G` | このセルの最後の内容行 | 文書の最終行 |
| `dG` | **このセルの中身だけ**を削除 | カーソル行から文書末尾まで削除 |
| `5G` | 文書の 5 行目（変わらず） | 文書の 5 行目 |
| `Ctrl+Home` / `Ctrl+End` | 文書の先頭 / 末尾（変わらず） | 同じ |

狙いは `dG` です。従来は以降のスライドまで巻き込んで消えていました。
`dgg` / `yG` / `cG`、VISUAL の `vG` / `VG` も同じようにセル内で止まります。

文書全体を対象にしたいときは `Ctrl+Home` / `Ctrl+End`、
または行番号を指定した `5G` を使ってください。

---

# 呼び出し方

| 方法 | |
| --- | --- |
| 設定モーダル | `⚙ 設定` の「セルモード」 |
| Vim ex コマンド | `:cellmode` / `:set cells` / `:set nocells` |
| Vim NORMAL | `gmc` |

設定は `localStorage` に残るので、次に開いたときも同じ状態です。
`OFF` にすると装飾・セル番号・キー割り当てがすべて消え、
従来のテキスト編集に戻ります。
