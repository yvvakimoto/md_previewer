# 定義リスト（用語集）

用語とその説明を対にして書く記法です。
用語を 1 行で書き、その次の行を `: ` （コロン＋空白）で始めると定義になります。
Pandoc / PHP Markdown Extra と同じ書き方で、通常プレビューでも Marp スライドでも使えます。

---

## 1. 基本形

用語行のすぐ下に `: 説明` を書きます。

Markdown
: プレーンテキストに書式を与える軽量マークアップ言語。

WebView2
: Microsoft の Chromium ベース埋め込みブラウザコントロール。

---

## 2. 1 つの用語に複数の説明

`: ` の行を続けて並べると、説明が複数並びます。

プレビュー
: 編集中の Markdown を整形表示する画面。
: ファイルの外部変更を検知して自動で再読み込みされる。

---

## 3. 連続するグループは 1 つのリストにまとまる

用語と説明の組を空行で区切って並べても、全体が 1 つの定義リストになります。

エクスポート
: 単一ファイルの HTML、または PDF を書き出す機能。

ワークスペース
: フォルダを開いてファイルツリーから複数の文書を行き来するモード。

Marp
: YAML フロントマターに `marp: true` を書くとスライドとして描画されるモード。

---

## 4. 空行を挟む書き方（loose 形式）

用語と `: 説明` の間に空行を入れても定義リストになります（Pandoc 互換）。
この形式では説明どうしの間隔がやや広くなります。

オフライン動作

: 依存ライブラリをすべて同梱しているため、実行時に CDN へアクセスしません。

自動更新

: 社内ファイル共有経由の任意機能で、既定では無効です。

> **注意** — この書き方を許容している副作用として、**普通の段落のあとに空行を挟んで `: ` で始まる行**が続くと、意図せず定義リストになります（Pandoc / PHP Markdown Extra も同じ挙動です）。
> 通常の文中で行頭にコロンを置きたいときは、全角の `：` を使うか、`\:` のようにエスケープしてください。

---

## 5. 複数行にわたる説明

継続行は **2 スペース以上** 字下げします。
日本語の場合、行末の改行は自動で連結されて 1 つの文として表示されます。

改行連結
: 段落の途中の単なる改行は同じ文の続きとして扱われます。
  日本語どうしの境界では余分な空白が入らないように連結され、
  英数字との境界ではスペースが保たれます。

---

## 6. 説明の中にブロックを置く

字下げを保てば、段落・箇条書き・コードブロック・画像などを説明の中に置けます。

ビルド手順
: 依存を取得してから実行ファイルをビルドします。

  ```powershell
  pwsh -File tools\install-deps.ps1
  cargo build --release
  ```

  `assets\` を実行ファイルの隣にコピーするのを忘れないでください。

対応フォーマット
: 次の 3 種類を扱えます。

  - `.md` / `.markdown` — 通常の Markdown
  - `.mdx` — Markdown と画像などを ZIP でまとめたバンドル
  - フォルダ — ワークスペースモード

サンプル画像
: 説明の中に画像を置くこともできます。

  ![サンプル|240](images/test.png)

---

## 7. インライン記法

用語にも説明にも通常のインライン記法が効きます。

**強調された用語**
: `インラインコード`、*斜体*、[リンク](sample.md)、そして
  [色付きテキスト]{color=#e91e63 weight=bold} が使えます。

脚注つきの用語[^dl]
: 脚注参照も説明の中に置けます[^dl2]。

[^dl]: 用語側に付けた脚注です。
[^dl2]: 説明側に付けた脚注です。

---

## 8. 他の記法との組み合わせ

`::: columns` で段組みにした中にも置けます。

::: columns
入力
: キーボードとマウス。

出力
: 画面とファイル。
+++
読み込み
: ディスクから取得する処理。

書き込み
: ディスクへ保存する処理。
:::

引用の中にも書けます。

> 定義リスト
> : 引用ブロックの内側でも同じように描画されます。

---

## 9. 定義リストにならない例

紛らわしい記法が誤って定義リスト化しないようになっています。

`::: center` などのフェンス（コロン 3 つ）は配置指定のままです。

::: center
これは中央寄せであって定義リストではありません
:::

表の配置指定行（`:---`）も表のままです。

| 左寄せ | 右寄せ |
|:-------|-------:|
| a      | b      |

コードブロックの中身はそのまま表示されます。

```text
用語
: これはコードブロックの中なので定義リストになりません
```

見出しやリスト項目は用語として扱われません。

# これは見出し
: この行はただの段落になります

---

## 10. 縦書き（tategaki.css）での挙動

`S` キーで `tategaki` スタイルを選ぶと、説明の字下げとアクセント罫線は
論理プロパティで指定されているため、縦書きの書字軸に沿った正しい辺に描画されます。

テーマ側では `--md-dl-accent` / `--md-dl-term-color` / `--md-dl-indent` /
`--md-dl-pad` / `--md-dl-gap` / `--md-dl-term-weight` / `--md-dl-desc-color`
を設定して見た目を変更できます。
