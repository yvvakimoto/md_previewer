    キーボードショートカット

    Hこのヘルプの表示 / 非表示
    Mダーク / ライト表示の切り替え
    Sスタイルの選択（行末の ⚙ でそのスタイル固有の設定。Marpモードでは Marpテーマ。フロントマターを書き換え）
    Nセクション自動番号の切り替え
    L行番号の表示切り替え
    W全幅レイアウトの切り替え
    Eエディタウィンドウを開く（Vimモード・数式入力補助・文字数カウント）
    Ctrl+N新規の空Markdownファイルを作成
    Ctrl+Dインストール先フォルダを Explorer で開く
    X現在の文書をエクスポート（保存ダイアログで HTML / PDF を選択。PDFはクリック可能なリンクと見出しのしおりを保持）
    Ctrl++ / Ctrl+- / Ctrl+0ズームイン / アウト / リセット
    Alt+← / Alt+→開いたファイルの履歴を戻る / 進む
    Ctrl+クリック.md リンクを新しいプレビュアのウィンドウで開く（通常のクリックは同じウィンドウで遷移）
    PMarp表示の切り替え: スクロール → デッキ → 一覧（一覧でサムネイルをクリックするとデッキで開く）
    F全画面表示の切り替え（Marp文書）
    Aスライドの自動縮小の切り替え（Marp）
    ← / → / PgUp / PgDn / Space前 / 次のスライド（Marpデッキモード）
    Home / End最初 / 最後のスライドへ（Marpデッキモード）
    Ctrl+Wheel / ドラッグカーソル位置でズーム / スライドをパン（Marpデッキモード）
    Z軌跡付きレーザーポインタの切り替え（Marpデッキモード）
