# 親階層参照（`../`）デモ

このファイルは `samples/parent-paths/demo.md` にあります。
画像 `test.png` は一つ上の階層の `samples/images/` にあるため、`../` で親階層を辿って参照します。

## 一階層上（`../images/test.png`）

![一階層上の画像|320](../images/test.png)

## 同階層との比較

ファイル自身のフォルダ（`parent-paths/`）には画像が無いので、上の `../` 参照だけが
正しく表示されれば、親階層以上のファイル参照が機能しています。

> 補足: `../` や `../../` のように開いている `.md` のディレクトリより上を辿るパスも
> `![]()` 構文で参照できます（画像・動画・`plotly` の `file:` も同様）。
