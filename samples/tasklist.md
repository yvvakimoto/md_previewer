# タスクリスト（チェックボックス）

`- [ ]` / `- [x]` で GitHub 形式のチェックボックスになります。
**プレビュー上のチェックボックスはクリックで付け外しでき、その 1 行だけがこの `.md` に書き戻されます。**
インデント・マーカーの種類・空白はそのまま保たれ、CRLF の改行コードも変わりません。

HTML / PDF / PNG に出力したものは操作できません（表示だけ）。

---

## 1. 基本形

- [x] 企画・要件定義
- [ ] 設計
- [ ] 実装

---

## 2. 入れ子

親と子は別の行なので、それぞれ独立に付け外しできます。

- [ ] リリース準備
  - [x] リリースノートを書く
  - [ ] インストーラをビルドする
  - [ ] タグを打つ
- [ ] 公開

---

## 3. 順序付きリスト

順序付きリストのマーカー（`1.` / `1)`）でも使えます。

1. [x] 見積もりを出す
2. [ ] 発注する
3. [ ] 検収する

---

## 4. ゆるいリスト（項目の間に空行）

項目の間に空行があると各項目が段落になりますが、チェックボックスは同じように扱われます。

- [x] 一次レビュー

- [ ] 二次レビュー

- [ ] 最終確認

---

## 5. 引用の中

引用（`>`）の中のタスクリストも書き戻しの対象です。

> レビューコメントより:
>
> - [x] 命名を直す
> - [ ] テストを足す

---

## 6. コードブロックの中は対象外

フェンスの中の `- [ ]` はただの文字列なので、チェックボックスにはならず、
書き戻しの数え上げからも除外されます。

```markdown
- [ ] これは記法の説明なのでチェックボックスにならない
- [x] 同上
```

通常の箇条書きと混在させても構いません。

- [ ] 混在した項目
- 通常の箇条書き（チェックボックスなし）
- [x] 混在した項目
