# 表（テーブル）

GFM のパイプ表は、プレビュー上で直接編集できます。表にマウスを乗せると右上に
**`Edit table`** が出るので、それを押すと編集モードに入ります。

- セルはその場で書き換えられます（表示は **Markdown のソース**に切り替わります）
- 行・列の挿入／削除と列の揃えは、**セルを右クリック**したメニューから
  （`Insert row above` / `Delete row` / `Insert column left` / `Align column center` など）
- **`Save`** で `.md` に書き戻し、**`Cancel`** で元に戻します

エディタウィンドウ（`E` キー）側にも表の支援があります。ステータスバーの
**`⊞ Table`** で行数・列数を指定して雛形を挿入でき（`:table 3 4` / `gti` /
`Ctrl+Alt+T` でも同じ）、**`Col: ON`** の間はカーソルがあるセルの列が全行にわたって
ハイライトされます（`:tablecol` / `gtc` / `Ctrl+Alt+H` で切替）。

## 基本形

| 項目 | 担当 | 状態 |
| --- | --- | --- |
| 設計 | Alice | 完了 |
| 実装 | Bob | 進行中 |
| テスト | Carol | 未着手 |

## 列の揃え

区切り行のコロンで揃えを指定します。編集モードの右クリックメニューからも変更できます。

| 左揃え | 中央揃え | 右揃え |
| :--- | :---: | ---: |
| a | b | 1 |
| aa | bb | 22 |

## 桁を揃えて書いた表

手で桁を揃えた表は、保存しても**その体裁のまま**書き戻されます（触っていない行は
1 バイトも変わりません）。

| Name  |   Role   | Since |
| :---- | :------: | ----: |
| Alice |   dev    |  2021 |
| Bob   | designer |  2023 |

## 詰めて書いた表

逆に詰めて書いた表も、詰めたまま保たれます。

|項目|値|
|-|-|
|幅|1280|
|高さ|720|

## セルの中の記法

セルには通常のインライン記法が書けます。編集モードではこれらが**ソースのまま**
表示されるので、記法が失われることはありません。

| 種類 | 例 |
| --- | --- |
| 強調 | **太字** と *斜体* |
| コード | `cargo build --release` |
| リンク | [sample.md](sample.md) |
| 数式 | $E = mc^2$ |
| 縦棒 | `a \| b` のように `\|` でエスケープ |

## 編集できない表

次のものは編集の対象外です（`Edit table` が出ないか、押すと理由をトーストで通知します）。

- **引用やリストの中に入れ子になった表** — ソースの行範囲を確実に特定できないため

> | 引用の中 | 表 |
> | --- | --- |
> | a | b |

- **`csv` / `tsv` コードブロックの表** — フェンス内の空行や末尾空白が描画時に落ちるため、
  往復すると元のデータと一致しなくなります（表示は下記のとおり普通に行われます）

```csv
製品,売上,前年比
ウィジェット A,1200,+12%
ウィジェット B,980,-3%
```

- **Marp スライドの表** — スライドは SVG の `foreignObject` の中にあるため対象外です
